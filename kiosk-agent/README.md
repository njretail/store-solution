# kiosk-agent (Windows 키오스크 PC 설치용)

브라우저는 보안상 자기가 떠 있는 컴퓨터를 재시작·종료할 수 없습니다(모든 브라우저
공통 제약, 우회 불가). 그래서 "기기 재시작 / 기기 종료 / 매일 자동 재부팅"을 실제로
동작시키려면, 이 PowerShell 스크립트를 키오스크 PC에 설치해 백그라운드로 돌려야 합니다.
"새로고침"과 광고/안내멘트/바코드판은 이 에이전트 없이 브라우저만으로 이미 동작합니다.

에이전트가 하는 일:
- **생존 신호**: 30초마다 서버에 상태를 묻는 것 자체가 신호입니다. 화면·에이전트 신호가 5분 넘게
  끊기면 관리자 화면에 "키오스크 응답 없음" 알림이 뜨고, 다시 연결되면 자동으로 해결 처리됩니다.
- **상태 점검**: 30분마다, 그리고 관리자 화면의 "지금 상태 점검"을 누르면 서버 응답·디스크·메모리·CPU·
  화면 실행 여부·장치 관리자 오류 장치(프린터, 결제 단말, 현금 방출기 등)를 점검해 보고합니다.
  이상이 있으면 "키오스크 오류" 알림이 뜹니다.
- **다시 로그인**: 키오스크 전용 브라우저 프로필(`ProfileDir`)을 지워 세션을 초기화한 뒤 화면을 다시 띄웁니다.
- **화면 자동 복구**: 키오스크 화면(브라우저)이 꺼지면 다시 띄우고, 그 사실을 오류로 보고합니다.
- 프로그램 재시작 / 기기 재시작 / 기기 종료 / 매일 자동 재부팅

## 1. 스크립트 준비

1. 이 폴더(`kiosk-agent.ps1`)를 키오스크 PC의 아무 곳에 복사합니다. 예: `C:\kiosk-agent\`
2. `kiosk-agent.ps1` 위쪽 `param(...)` 값을 채웁니다.
   - `KioskId`: 관리자 화면(키오스크 관리)에서 등록한 키오스크의 ID. Supabase 테이블
     편집기에서 `kiosks` 테이블을 열어 해당 행의 `id` 값을 복사하면 됩니다.
   - `ApiBase`: 실제 서비스 주소 (`https://store-solution-one.vercel.app` 그대로 두면 됨)
   - `BrowserPath`: 키오스크로 쓸 브라우저 실행 파일 경로 (기본값은 Chrome 기본 설치 경로)
   - `ProfileDir`: 키오스크 전용 브라우저 프로필 폴더 (기본값 `C:kiosk-agentchrome-profile` 그대로 두면 됨)
3. 파일을 메모장으로 고쳐 저장할 때는 인코딩을 **UTF-8(BOM)** 으로 저장하세요. BOM 없이 저장하면 Windows
   PowerShell 5.1이 한글을 잘못 읽어 스크립트가 실행되지 않을 수 있습니다.

## 2. Windows 시작 시 자동 실행 등록 (작업 스케줄러)

1. 시작 메뉴에서 "작업 스케줄러" 실행
2. 오른쪽 "작업 만들기" 클릭
3. **일반** 탭: 이름 `kiosk-agent`, "가장 높은 권한으로 실행" 체크, "사용자가 로그온했는지
   여부에 관계없이 실행" 선택 (기기 재시작/종료 권한을 위해 꼭 필요)
4. **트리거** 탭: 새로 만들기 → "컴퓨터 시작할 때"
5. **동작** 탭: 새로 만들기 →
   - 프로그램/스크립트: `powershell.exe`
   - 인수 추가: `-ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\kiosk-agent\kiosk-agent.ps1"`
6. 저장 (관리자 계정 암호 입력 요청 시 입력)

이제 컴퓨터를 재시작하면 에이전트가 자동으로 켜지고, 키오스크 화면도 자동으로 뜹니다.

## 3. 동작 확인

- 관리자 화면(키오스크 관리)의 "연결" 칸이 1분 안에 **연결됨**으로 바뀌는지 확인하세요.
- "지금 상태 점검"을 누르고 30초 뒤 새로고침하면 점검 결과가 보여야 합니다.

- 관리자 화면(키오스크 관리 > 기기 상태·원격 관리)에서 "프로그램 재시작" 버튼을 눌러보고
  30초 안에 브라우저가 재시작되는지 확인하세요.
- "매일 자동 재부팅" 시각을 설정해두면, 그 시각에 컴퓨터가 자동으로 재부팅됩니다.

## 참고

- 에이전트가 켜질 때 서버에 남아 있던 예전 명령(예: 전에 보낸 "기기 재시작")은 다시 실행하지 않습니다.
  (예전 버전은 재시작 후 같은 명령을 또 실행해 재부팅이 반복될 수 있었습니다 — 새 버전으로 교체하세요.)
- 결제기·현금 방출기 업체 프로그램이 오류를 직접 알려줄 수 있다면 `POST /api/kiosk/<키오스크ID>/errors`
  에 `{"message": "동전 방출기 걸림", "device": "동전 방출기"}` 형식으로 보내면 바로 알림이 뜹니다.

- 폴링 주기는 30초입니다(`kiosk-agent.ps1`의 `$PollSeconds`). 더 빠른 반응이 필요하면
  값을 줄이되, 너무 짧게(예: 5초 미만) 하면 서버에 불필요한 요청이 많아집니다.
- 네트워크가 잠깐 끊겨도 스크립트는 죽지 않고 다음 주기에 다시 시도합니다.
- "기기 종료"는 매장에 직접 가야 다시 켤 수 있으니, 관리자 화면에서도 확인 창이
  한 번 더 뜨도록 해뒀습니다.
